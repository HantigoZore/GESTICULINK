# Código Página Web

El actual código es de la página web en blanco con el cual solo abre la cámara para conectarlo con el servidor local.

Es necesario usar el código en python en la terminal de la carpeta donde está el archivo HTML y estilos:

’’’python
python -m http.server 8000
’’’

O también usar la extensión de VS Code: Live Server para correr de una vez el archivo HTML sin usar comandos.
